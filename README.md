# CampusFix 🏫

Smart Campus Issue Reporting and Prioritization System.

## Problem

Campus issues such as electrical faults, water leakage, damaged infrastructure,
and cleanliness problems are often reported through informal or unstructured
channels. This can make it difficult for authorities to identify urgent issues.

## Solution

CampusFix provides a structured issue-reporting system that automatically
prioritizes complaints based on:

- Severity
- Safety risk
- Number of students affected

Administrators can view reported issues through a dashboard and update their
status.

## Features

- 📝 Structured issue reporting
- 🧠 Explainable priority calculation
- 🔴 High / 🟡 Medium / 🟢 Low priority
- 📊 Admin dashboard
- 📌 Issue status tracking
- 💾 CSV-based data storage
